What we learned

Flat ground is solved. Slopes are the gap.

01

Both leg designs passed every run on flat, hard ground.

02

On a ramp the hanging package tilts to the slope before the legs can adjust. Above 20° that is too late.

03

The hook can open early if the package drops suddenly, so the winch has to lower smoothly.
